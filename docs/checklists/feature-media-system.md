# Media System Checklist

## Goal

Keep media behavior unified across GPT handoff, focused upload, regular web upload, event upload, and later public contribution.

## Checklist

### Canonical model

- [x] Define the canonical media flow
- [x] Define subject photo vs event photo roles
- [x] Define hero image rules
- [x] Define public contribution image rules
- [x] Define likely media metadata

### Upload interaction

- [ ] Define the exact shared UI grammar for choose / drag-drop / paste
- [ ] Decide where desktop-only hints appear versus mobile hints
- [ ] Define replace / remove behavior in detail

### Crop interaction

- [x] Define the crop slider middle-start rule
- [x] Define zoom-out and zoom-in behavior
- [x] Define shared crop consistency across surfaces
- [ ] Decide whether first version supports only fixed-aspect crop or multiple aspect options

### Attachment behavior

- [ ] Define whether a subject can have multiple images in first version
- [ ] Define how hero selection works when multiple images exist
- [ ] Define how event media appears on the subject page without blurring event-vs-subject roles

### Public and moderation concerns

- [ ] Define authorship display for contributed media
- [ ] Define moderation / removal rules for public contribution images
- [ ] Define whether public contribution media can ever become the canonical hero without steward action

### Output

- [ ] This feature area is ready when media implementation decisions can be made from the checklist rather than by re-arguing the upload model each time
