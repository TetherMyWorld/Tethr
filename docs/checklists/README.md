# Tethr Checklists

## Purpose

This folder holds actionable working checklists derived from the master spec.

The master spec in [tethr-architecture.md](/F:/Tethr/TethrArca/docs/tethr-architecture.md) defines the system.
These checklist files define the work that needs to be done.

## What belongs here

Use this folder for:

- phase checklists
- feature checklists
- workflow design checklists
- implementation-prep checklists
- validation checklists

## What does not belong here

Do not use this folder for:

- raw brainstorm notes
- long-term philosophy
- implementation diffs
- final release notes

Those belong in:

- [tethr-architecture.md](/F:/Tethr/TethrArca/docs/tethr-architecture.md)
- [change-log.md](/F:/Tethr/TethrArca/docs/change-log.md)
- [decision-log.md](/F:/Tethr/TethrArca/docs/decision-log.md)

## Checklist Rule

A checklist should be:

- specific
- actionable
- scoped
- easy to mark complete

If a task is too vague to check off, it probably belongs in the spec first.
